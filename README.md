
# Personal Expense Tracker

## Project Overview
A Python-based console application for tracking personal expenses, managing expense records, and calculating total expenditures.

## Features
- Add expenses with categories and amounts
- View all recorded expenses
- Calculate total expenses
- Remove selected expenses
- Save and load expense records using a text file
- Validate user input and handle errors

## Technologies
- Python
- File Handling (TXT)
- Data Structures (Lists and Dictionaries)
- Exception Handling
